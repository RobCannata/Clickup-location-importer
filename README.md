# ClickUp Location Importer

Single-file browser tool for importing store locations into a selected ClickUp List.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings** → **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**.
6. Save and wait for the GitHub Pages URL.

The public link will look like:

`https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`

## Use

1. Open the published page.
2. Paste your ClickUp API token.
3. Connect to ClickUp.
4. Select Workspace, Space, Folder, and List.
5. Upload the CSV.
6. Test the first row.
7. Run the full import.

## Security

Do not hard-code or commit a ClickUp API token into `index.html` or any public repository.
